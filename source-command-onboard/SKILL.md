# source-command-onboard

Use this skill when the user asks to run the migrated source command `onboard`.

## Command Template

# onboard

What is this project repository in simple, easy to understand, clear, crisp precise exact words, explanatory, understandable to a mid-level programmer; no metaphors.

What's the flow of this product from input to final end output? What are core/main components, live where - that one must know before being able to do development in this project. Assume that I dont know mostly anything about the product, project, etc.

Don't do any coding changes or  execution of any Git/GitHub commands.



This command will be available in chat with /onboard
